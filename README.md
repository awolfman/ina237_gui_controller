# ina237_gui_controller

GUI приложение для управления мониторами питания INA237 через I2C.

## Возможности

- 🔹 Поддержка FTDI FT232H и CH341T
- 🔹 **ДЕМО-РЕЖИМ** - работа без реального оборудования
- 🔹 Поддержка нескольких устройств INA237 на одной шине
- 🔹 Мониторинг VBUS, CURRENT, POWER в реальном времени
- 🔹 Чтение/запись регистров

## Установка

```bash
pip install -r requirements.txt
python main.py


    Выберите интерфейс ("demo" для симуляции)

    Нажмите "Подключить"

    Нажмите "Scan" для поиска устройств

    Выберите вкладку устройства

Демо-режим

При выборе интерфейса "demo" создается симулятор INA237 с:

    Тремя виртуальными устройствами

    Генерацией случайных значений

    Возможностью тестирования всего функционала
