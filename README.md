# INA237 Controller

**GUI-приложение для управления мониторами питания INA237 через I2C**

Поддерживает локальное подключение через **FTDI FT232H** (pyftdi) и удалённое подключение по **Ethernet/SSH** (paramiko + i2cget/i2cset). Работает с несколькими устройствами на одной шине, позволяет читать/записывать регистры, мониторить напряжение, ток, мощность и температуру в реальном времени.  
**Демо-режим** позволяет тестировать интерфейс без реального оборудования

---

## 📋 Основные возможности

- 🔌 **Поддержка интерфейсов** (Linux):
  - **FTDI FT232H** – через `pyftdi` (USB)
  - **Ethernet/SSH** – удалённый доступ через `paramiko` + `i2cget`/`i2cset`
  - **Демо-режим** – встроенный симулятор (опция `--demo`)
  - **CH341T** – не поддерживается в Linux в текущей реализации (требуется `ch341dll` для Windows)

- 📊 **Измерения**:
  - VBUS, CURRENT, POWER, VSHUNT, DIETEMP

- 📖 **Регистры**:
  - Чтение/запись, раскрытие битовых полей, побитное редактирование

- 🖥️ **GUI**:
  - Вкладки для нескольких устройств, мониторинг в реальном времени, обработка ошибок

## 🚀 Ултановка и запуск

### 1. Тстановка зависимостей
```bash
pip install -r requirements.txt
```

**Dly FTDI FT232H:**
```bash
pip install pyftdi
```

**Удуляеторенное для Ethernet/SSH**
```bash
pip install paramiko
```

### 2. Запуск
```bash
# Боевой режим - автоматический поиск FTDR или Ethernet
python main.py

# Демо-режим
python main.py --demo
```

## 🕥 қспользование

### Подключение через Ethernet (SSH)
1. Выберите интерфейс `ethernet`.
2. Нажмите ⚙ Настроить Ethernet и введите:
   - IP-адрес/хост
   - Номер I2C шины (slot)
   - Имя пользователя (обычно root)
   - Пароль (может быть пустым, если используется SSH-ключ)

3. Нажмите Подключить, затем Scan – найденные устройства появятся во вкладках.

### Управление устройством
- 📖 Read All – чтение всех регистров и обновление измерений.
- 📊 Read Measurements – обновление только полей VBUS, CURRENT, POWER, VSHUNT, TEMP.
- Монитор – циклический опрос с заданным интервалом.
- Регистры: кнопки 📖 (читать), 💾 (записать), ▼ (раскрыть биты). Для CONFIG и ADC_CONFIG доступно побитное редактирование.

### Особенности
- Порядок байт определяется автоматически (Big/Little Endian).
- Пустой пароль поддерживается (SSH-ключ).
- Все ошибки логируются в консоль.

## 📝 Примечания
- **Ethernet-подключение** использует `i2cget`/`i2cset` - на удалённой машине должны быть установлены `i2c-tools`.
- **CH341T** в Linux не через поддерживается в текуыей версии (требуется доработка через yfd» ли ядерный дравер).
- **Демо-режим** не требует оборудования и полезен для ознакомления с интерфейсом.
